# ChessQuest

ChessQuest is an educational chess system designed for young developing players in Years 4–8. It combines chess gameplay with varied difficulty levels and a reward system to encourage concentration, problem-solving, strategic thinking, and learning from mistakes.

Players can challenge chess bots with different levels of difficulty while earning rewards as they progress. The system is designed to provide a more engaging and motivating learning environment than a standard chess game.

## Development Status

**In Development** — ChessQuest is actively being developed. Features, AI difficulty, gameplay systems, and the user interface are still being improved and tested.

## Features

- Chess gameplay against AI opponents
- Multiple difficulty levels
- Reward and progression system
- Educational focus for younger players
- Graphical user interface
- Chess move validation and game-state management
- Check, checkmate, stalemate, and draw detection
- Pawn promotion
- Sound effects and visual feedback

## Technologies

- Python
- Pygame
- CustomTkinter
- Python-Chess

## Installation

1. Install Python 3.10 or newer.
2. Clone the repository:

```bash
git clone https://github.com/your-username/ChessQuest.git
cd ChessQuest
```

3. Install the required dependencies:

```bash
pip install pygame customtkinter python-chess
```

## Usage

Run the main program:

```bash
python startup.py
```

Use the graphical interface to start a game, select a difficulty, and play against the chess bot.
