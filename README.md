# ChessQuest

# Cause of why I'm making this project

Chess has been around for a long time since 600CE, where it was first called Chaturanga, being very popular at the time and still is today. Today we have many chess players at young ages now that transcend the game of chess, creating new combinations. With only 7.29% according to the chess championship website, this leads me to wonder why this is the case? With the answer being that chess now is too hard to learn with all these new tactics and that is why I want to create software where people can learn. I want my target audience to be young children from the ages of 4-8. As they can find it hard to remain focused on certain activities such as education in school or other activities that require deep concentration, problem solving, and learning from mistakes. Chess helps this out by providing an environment to think and take logical steps to the solution. Where children must concentrate on the game, consider what is the best move for them and how they can learn from losing their previous matches. Statistics show that chess can increase learning capabilities, leading to improved grades. This makes the solution to chess most benefitable towards these younger generations.  

 

The problem I see with the current system (Chess.com) is that they provide inadept learning features. The way I want to solve this is that I want to combine learning with a progression/reward system to make practice more engaging. Examples of these are rocksteady where they make a combination of a game and an education system so that young children can learn much more easily and would be more motivated to continue learning.  Where there would be a shop-based system that would allow users to customize features of the software such as their chess pieces or the board design. Moreover, I will add a game review system that helps users understand. As in the current game review system on chess.com it would just say what was the good and bad moves you did and only would sometimes show what move to do without even explaining the reasoning behind it. Additionally, in my software there would be a large range of AI Elo bots to compete against. This is a problem in the current system as there are only set Elo ranges that you can battle against where when advancing the Elo jump can be considerably large, making it too difficult for users to compete or adapt against.
